# My Tiles Calculator

A Bengali/English tile calculator PWA for floor, wall, skirting, shelf and stair tiles.

## Features
- Floor & Skirting tiles
- Wall tiles with color distribution
- Shelf / Kitchen slab (Tak)
- Stair tiles
- Bilingual (Bengali / English)
- Dark mode support
- Offline-ready (PWA with Service Worker)

## Hosting on GitHub Pages
1. Upload all files to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your app will be live at `https://<username>.github.io/<repo-name>/`
